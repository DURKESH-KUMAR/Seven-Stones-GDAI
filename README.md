# Seven Stones - GDAI

This repository contains the development of **Seven Stones**, a digital adaptation of the traditional Indian game, built as part of the **Game Development and Artificial Intelligence (GDAI)** curriculum. The project focuses on implementing gameplay mechanics, artificial intelligence, multiplayer systems, and interactive game design using Unity.

---

## About

Seven Stones is a modern recreation of the classic outdoor game, combining traditional gameplay with contemporary game development techniques. The project explores core game development principles including gameplay programming, physics, user interface design, artificial intelligence, and multiplayer architecture.

This repository serves as both a learning resource and a portfolio project demonstrating practical game development skills.

* Unity Hub
